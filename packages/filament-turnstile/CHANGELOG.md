# Changelog

All notable changes to this project are documented in this file.

## 1.1.0 - 2026-07-16

- Add Laravel 13 support to the Illuminate dependency constraints.
- Declare Illuminate Validation directly because the plugin uses its validation contracts and exceptions.
- Add Orchestra Testbench 11 support for the Laravel 13 test environment.
- Allow PHPUnit 11.5 and 12.5 for the supported PHP and Laravel test matrix.
- Document the PHP 8.3 minimum imposed by Laravel 13.

## 1.0.0 - 2026-07-13

- Initial Filament 5 release.
